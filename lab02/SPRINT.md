# Sprint 1 — LabLoans

## Sprint Goal

By the end of Sprint 1, the lab can trace every newly issued item to a borrower and confirm its return and condition.

## Selected items

- [F] The lab technician can record each equipment loan against an identified borrower and a due date.
- [F] Borrowers can see the equipment they currently hold and when each item is due.
- [F] The lab technician can record an item's return and its condition.

## Definition of Done

- [ ] A lab technician can issue an available test item to a test borrower with a due date, and the saved loan shows all three values correctly.
- [ ] The test borrower can sign in and see the issued item and due date, but cannot see another borrower's loan.
- [ ] A lab technician can return the test item, record its condition, and the item no longer appears in the borrower's active loans.
- [ ] Acceptance tests for issuing, viewing, and returning an item pass in the agreed test environment.
- [ ] The client representative has reviewed the Sprint Goal scenario and recorded acceptance of the increment.
